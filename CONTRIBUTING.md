# Contributing to RUHI

Thanks for stopping by! RUHI is a **personal, learning-first project** I build in my spare time, mostly with AI-assisted coding. I'm still learning, so friendly feedback is very welcome.

## Ways to help

- 🐛 **Report a bug**: open an issue with what you did, what you expected, what happened, and your OS/Python version (plus logs if you have them)
- 💡 **Suggest an idea**: open an issue describing the problem it solves
- 📖 **Improve the docs**: typo fixes and clearer setup steps are always appreciated
- 🔧 **Send a pull request**: for anything bigger than a small fix, please open an issue first so we can chat about it

## Pull request basics

1. Fork the repo and create a branch: `git checkout -b fix/short-description`
2. Keep changes small and focused
3. Never commit API keys or `config` files with secrets
4. Describe what you changed and how you tested it

## Be kind

Be respectful and patient. Everyone here is learning.
